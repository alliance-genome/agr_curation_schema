    NucleicAcidSource

    A biological-source or library-membership description scoped to one record. A reusable library may be referenced without copying its properties into every membership.

    Slots

    Name Description
    created_by The individual that created the entity.
    date_created The date on which an entity was created. This can be applied to nodes or edges.
    date_updated Date on which an entity was last modified.
    db_date_created The date on which an entity was created in the Alliance database. This is distinct from date_created, which represents the date when the entity was originally created (i.e. at the MOD for imported data).
    db_date_updated Date on which an entity was last modified in the Alliance database. This is distinct from date_updated, which represents the date when the entity was last modified and may predate import into the Alliance database.
    internal Classifies the entity as private (for internal use) or not (for public use).
    obsolete Entity is no longer current.
    references holds between an object and a list of references
    source_age Age of the biological material from which the nucleic acid originated, preserving the source wording separately from developmental stage.
    source_cloning_sites Cloning sites recorded at source-library scope.
    source_genetic_background Affected genomic model representing the genetic background of the biological material from which the nucleic acid originated, rather than the cloning or propagation host.
    source_library Reusable library for this membership. Keep member-specific provenance on this source detail.
    source_library_membership_relation Original relation between this reagent and its source library, such as member_of_reagent_collection.
    source_library_name Original name of the source library or collection.
    source_library_type Original source classification of this library, for example reagent collection or assay dataset.
    source_stage Developmental-stage ontology term for the biological source; FlyBase uses FBdv terms through FBDVTerm.
    source_stage_free_text Original source stage wording when no suitable ontology mapping has been established; do not put free text in the ontology reference.
    source_tissue Anatomical ontology term for the biological source tissue; FlyBase uses FBbt terms through DAOTerm.
    source_tissue_free_text Original source tissue wording when no suitable ontology mapping has been established; do not put free text in the ontology reference.
    source_vector Identified vector at source-library scope, not evidence about an individual insert.
    source_vector_name Vector name recorded for this library membership; do not promote it to a clone-specific fact.
    source_vector_type Vector type recorded for this source library. Proposed CV: Clone Vector Type.
    updated_by The individual that last modified the entity.
