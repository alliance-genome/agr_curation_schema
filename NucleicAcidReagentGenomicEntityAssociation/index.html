    NucleicAcidReagentGenomicEntityAssociation

    A typed, evidenced nucleic-acid-record-to-genomic-entity relationship. Keep computed support, hybridization, amplification, encoding and overlap semantically distinct. It is not an expression-detection assertion.

    Slots

    Name Description
    created_by The individual that created the entity.
    date_created The date on which an entity was created. This can be applied to nodes or edges.
    date_updated Date on which an entity was last modified.
    db_date_created The date on which an entity was created in the Alliance database. This is distinct from date_created, which represents the date when the entity was originally created (i.e. at the MOD for imported data).
    db_date_updated Date on which an entity was last modified in the Alliance database. This is distinct from date_updated, which represents the date when the entity was last modified and may predate import into the Alliance database.
    evidence The evidence that supports some assertion.
    internal Classifies the entity as private (for internal use) or not (for public use).
    nucleic_acid_reagent_association_subject A nucleic-acid material, primer-pair definition or sequence record. The historical slot name also covers the explicitly listed nonmaterial classes.
    nucleic_acid_reagent_genomic_entity_association_object The genomic entity related to this material, preserving gene, transcript, CDS or variant identity.
    obsolete Entity is no longer current.
    reagent_association_method Method supporting this particular relationship, for example AEVAST with BLAST. Absence does not imply manual curation.
    reagent_association_method_version Recorded method version. Omit when unrecorded, including FlyBase AEVAST links for which no version was retained.
    reagent_association_source_relation Original relationship value or a documented normalization of its source tag (for example, WormBase Positive_gene to positive_gene), preserving its meaning. Retain an empty string when that is the original encoding. Omission means not supplied; notes can record SQL NULL or other missing-value encodings.
    reagent_association_source_release Source release of this relationship and its computational derivation, where known.
    related_notes Holds between an object and a list of related Note objects.
    relation A high-level grouping for the relationship type. This is analogous to category for nodes. In RDF, this corresponds to rdf:predicate and in Neo4j this corresponds to the relationship type.
    source_association_identifier Provider-qualified original association identifier, where supplied; not a newly minted public ID.
    supporting_sequence_identifiers Original identifiers of sequences supporting this relationship; retain accessions or provider-qualified source IDs even when no separate sequence entity has been loaded.
    supporting_transcript_identifiers Transcript identifiers on the derivation path to a gene association. A derived gene link must not erase its transcript-level support.
    updated_by The individual that last modified the entity.
