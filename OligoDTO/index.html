    Slots

    Name Description
    created_by_curie Curie of the Person object representing the individual that created the entity
    cross_reference_dtos None
    data_provider_dto Ingest object representing the organization (e.g. MOD) from which the data was sourced and a CrossReference to that organisation's site
    date_created The date on which an entity was created. This can be applied to nodes or edges.
    date_updated Date on which an entity was last modified.
    db_date_created The date on which an entity was created in the Alliance database. This is distinct from date_created, which represents the date when the entity was originally created (i.e. at the MOD for imported data).
    db_date_updated Date on which an entity was last modified in the Alliance database. This is distinct from date_updated, which represents the date when the entity was last modified and may predate import into the Alliance database.
    derived_from_reagent_identifiers Primary external IDs or provider-qualified internal IDs of separately submitted nucleic-acid reagents used as starting materials for this reagent.
    generated_by_identifiers Source identifiers of the Agents that generated the material. Match generated_by cardinality; Agent identifier resolution remains a downstream implementation requirement.
    internal Classifies the entity as private (for internal use) or not (for public use).
    mod_internal_id The model organism database (MOD) internal identifier for the object
    name a human-readable name for an entity
    note_dtos None
    nucleic_acid_reagent_synonym_dtos Inline alternative name annotations retaining each name’s evidence and metadata.
    nucleic_acid_reagent_type_name Name of the runtime VocabularyTerm for the provider-supported material subtype, such as EST for a confirmed cDNA clone. Proposed CV: Nucleic Acid Reagent Type.
    nucleic_acid_source_dtos Ingest details for library memberships and source-scoped provenance. Retain multiple memberships and their original scopes.
    obsolete Entity is no longer current.
    oligo_chemical_type_name Runtime vocabulary name for oligonucleotide chemistry.
    oligo_modification_names Runtime vocabulary names for reported oligonucleotide modifications.
    oligo_sequence Source-reported oligonucleotide sequence in its recorded 5-prime to 3-prime orientation.
    oligo_sequence_context_name Runtime term name for source-supported insert, vector or mixed sequence context.
    placeholder A boolean property to indicate whether a data record/object/entity is intended to be a placeholder data object rather than a publicly displayed object with a proper ID, name and/or symbol, for example. For example, the Cassette class has been introduced to support FlyBase Cassette objects with IDs and names, but not every Alliance member has data tables/classes for these objects and any IDs or names/symbols would likely be derived and not helpful to end users. Data records/entities where the placeholder value is set to true would have various visible properties suppressed, so as not to confuse end users with private, internal or otherwise contrived representations.
    primary_external_id The primary external (non-Alliance) database identifier/curie for the object. Note that this may be an external (non-Alliance member) identifier for an object, like a UniProt ID for a protein, and may act as the MOD's/Alliance member's primary key for the entity.
    reagent_availability_name Name of the runtime VocabularyTerm for source-reported material availability. Proposed CV: Reagent Availability; available, not available and unknown are distinct. Being unavailable does not make a sequence record a material.
    reagent_preparation_protocol Source preparation or use instructions, including source-supplied protocol URLs. Instructions do not establish a separate preparation identity.
    reagent_primer_pair_identifiers Identifiers of primer-pair definitions used in reagent preparation or use.
    reagent_sequence_dtos Ingest details for sequence evidence describing this material or sequence record; each sequence retains its own role and source identifier.
    reference_curies External reference curies used for ingest
    secondary_identifiers None
    taxon_curie Curie of the NCBITaxonTerm representing the taxon from which the biological entity derives
    updated_by_curie Curie of the Person object representing the individual that updated the entity
